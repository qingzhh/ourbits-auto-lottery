# OurBits 自动抽奖

![version](https://img.shields.io/badge/version-1.01-blue)
![license](https://img.shields.io/badge/license-MIT-green)
![platform](https://img.shields.io/badge/userscript-Tampermonkey%20%7C%20Violentmonkey-orange)

OurBits（`lottery.php`）油猴自动抽奖脚本：无刷新直连 / 跨页续航双引擎，十连抽与单抽，保底魔力熔断，中奖统计与单 GB 净成本计算。

## 一键安装

1. 先安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 安装脚本：

👉 **[一键安装 OurBits 自动抽奖 v1.01](https://raw.githubusercontent.com/qingzhh/ourbits-auto-lottery/main/ourbits-auto-lottery.user.js)**

脚本管理器会弹出安装页，点「安装」即可。之后打开 <https://ourbits.club/lottery.php>，右上角会出现控制面板。

> 如果点击后只看到源码，请在脚本管理器的「实用工具 / 导入」里粘贴 raw 链接，或下载 `.user.js` 文件后拖入浏览器。

## 功能

- **双引擎执行**：默认「无刷新直连」，页面不跳转；异常时可切「跨页续航」，由脚本记录会话自动续跑。
- **抽奖策略**：十连抽（送 1 次）/ 单抽，指定轮数 / 一抽到底。
- **风控保护**：自定义保底魔力熔断线、请求间隔与随机抖动，避免高频请求。
- **实时统计**：7 类奖项的次数与占比、净上传收益、单 GB 净魔力成本。
- **数据管理**：统计与配置保存在脚本管理器本地存储，支持 JSON 导入导出与一键清空。
- **面板体验**：可拖动、可折叠，跟随站点暗色主题。

## 使用步骤

1. 打开 <https://ourbits.club/lottery.php>，确认页面右上角出现「🎰 OurBits 自动抽奖」面板。
2. 选择执行引擎、抽奖方式与运行策略，填入保底魔力、请求间隔和抖动。
3. 点「开始自动抽奖」；运行中按钮变为「停止自动抽奖」，可随时手动停止。
4. 需要留档时用「导出JSON」保存统计，换设备后「导入JSON」恢复。

## 两种执行引擎

| 引擎 | 行为 | 适用场景 |
| --- | --- | --- |
| 无刷新直连 | 用 `fetch` 提交抽奖并解析返回页，页面不跳转 | 默认首选，速度快、无刷新 |
| 跨页续航 | 模拟点击提交，页面跳转后靠会话记录自动继续 | 直连抓不到结果或站点校验较严时 |

## 统计口径

- 净上传 = 增加上传量 − 减少上传量
- 净耗魔力 = 总投入魔力 − 返还魔力 − 临时 VIP 补偿魔力
- 单 GB 净成本 = 净耗魔力 ÷（净上传 MB ÷ 1024）

## 常见问题

- **提示「未捕获到开奖结果」**：站点返回结构可能变化，切换到「跨页续航」再试。
- **提示魔力不足 / 触发频率限制**：脚本会自动停止；请降低目标轮数或提高间隔、抖动。
- **面板不显示**：确认当前在 `lottery.php` 页面、脚本已启用、未被其他扩展拦截。
- **如何更新**：脚本带 `@updateURL`，脚本管理器会自动检查；也可重新点安装链接覆盖旧版本。
